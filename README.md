# Student Attendance & Performance Tracker
A Python-based system built to analyze the correlation between student attendance and academic performance.

## 🚀 Features
- **Data Modeling:** Uses SQLite with 4 relational tables.
- **Attendance Tracking:** Automated percentage calculation.
- **Performance Analytics:** Subject-wise scoring and pass/fail logic.
- **Smart Insights:** Generates warnings for low attendance affecting marks.

## 🛠️ Tech Stack
- Language: Python 3.x
- Database: SQLite3
- Version Control: Git

## 📖 How to Run
1. Clone this repo.
2. Run `python main.py`.
